# 切片参数逐项说明

> 只覆盖**App 里已经接入**的参数。键名与默认值取自 `libslic3r/PrintConfig.cpp` 的
> `set_default_value()`，不是凭印象写的。
>
> 阅读方式：`调大 →` / `调小 →` 后面是**实际后果**，不是"效果更好"这类空话。

---

## 质量

| 参数 | 默认 | 说明 |
|---|---|---|
| 层高 | 0.2mm | 决定表面精度和总时长。0.08 很细但慢 3 倍；0.28 快但层纹明显。**引擎限制：层高 ≤ 0.75 × 线宽**，0.4 线宽下最大 0.3，写 0.4 会直接报 `Too small line width` |
| 线宽 | 0.42mm | 一般设成喷嘴直径 1.05 倍。调大 → 出料多、强度高、细节糊；调小 → 细节好但容易断丝 |
| 外墙层数 | 2 | 调大 → 强度和密封性提升，时间和耗材线性增加。功能件建议 3 |

## 壳层

| 参数 | 默认 | 说明 |
|---|---|---|
| 顶部壳层数 | 4 | 决定顶面是否"塌陷"。少于 3 层时顶面容易出现凹坑 |
| 顶部壳厚 | 0.6mm | 与层数**取较大者**生效。设 0 表示只按层数算 |
| 底部壳层数 | 3 | 底面直接贴床，少一层影响不大，但太少会透光 |
| 底部壳厚 | 0 | 默认只按层数算 |
| 垂直壳厚 | 保证 | `保证`=所有斜面都补实心；`仅关键`=只补陡坡；`关闭`=省时但斜面会露填充 |
| 首层单壁 | 关 | 开启后首层只打一圈壁，减少首层溢料和"象腿" |

## 顶底面图案

| 参数 | 默认 | 说明 |
|---|---|---|
| 顶面 | 单调线 | `单调线`(monotonicline) 每层同向，外观最整齐；`同心` 适合圆形件；`希尔伯特` 填充最均匀但慢 |
| 底面 | 单调线 | 同上 |
| 内部实心 | 单调线 | 只在实心层生效 |

> ⚠️ 枚举值必须是引擎里的原名。`直线` 对应的是 `line`，**不是** `rectilinear`
> （PrusaSlicer 的名字，Bambu 没有）。写错会被静默忽略。

## 接缝与顺序

| 参数 | 默认 | 说明 |
|---|---|---|
| 接缝位置 | 对齐 | `对齐` 把接缝排成一条竖线，好看但强度弱；`最近` 最省时；`背面` 藏到背面；`随机` 分散受力点 |
| 打壁顺序 | 内→外 | `外→内` 外观更好（外壁贴着已打好的内壁），但悬垂能力差 |
| 熨烫 | 关 | 开启后喷嘴不挤料、贴着顶面再走一遍，能把顶面熨平。费时约 20% |

## 尺寸补偿

| 参数 | 默认 | 说明 |
|---|---|---|
| 象腿补偿 | 0 | 首层内缩量。热床边缘受热外扩，0.1~0.2 能明显改善 |
| XY 孔补偿 | 0 | **正值缩小孔**。装配孔偏紧时给负值 |
| XY 轮廓补偿 | 0 | 正值放大外形。偏松时给负值 |

## 耗材与温度

| 参数 | 默认 | 说明 |
|---|---|---|
| 耗材类型 | PLA | 换类型会同时改**温度 / 密度 / 体积极限流速**三项。以前这里硬编码 PLA，用 PETG 会按 220℃ 打（PETG 要 255℃），直接打废件 |
| 打印板型 | 纹理 PEI | 热床温度在引擎里**按板型分开存**，不是同一个数。换板型等于换掉实际下发的温度键 —— 所以「板型选错」会让温度完全不生效，而不是温度数值偏差 |
| 喷嘴温度 | 220℃ | 按耗材预设值来。调高 5℃ 能改善层间结合，代价是拉丝变多 |
| 首层温度 | 跟随 | ABS/PC 首层通常比其余层低 5~10℃ 防翘边。0 表示跟随喷嘴温度，第 2 层起自动切回主温度 |
| 热床温度 | 60℃ | 首层附着力主要靠它。PETG 要 80℃、ABS 要 90℃，低了会翘边 |
| 体积极限流速 | 按耗材 | **硬限速**，见下 |

### 体积极限流速为什么这么重要

引擎在生成每一段挤出路径时都做一次：

```
speed = min(设定速度, filament_max_volumetric_speed / path.mm3_per_mm)
```

0.4mm 喷嘴、0.2mm 层高、0.42mm 线宽时每毫米体积约 **0.084mm³**，
上游默认限速只有 **2.0**，于是：

```
2.0 / 0.084 ≈ 24mm/s
```

即使速度面板填 200，实际也只跑 24mm/s —— **速度参数看起来完全失效**。
App 里按耗材给了一组合适值：PLA 12（≈143mm/s）、PETG 25、ABS 28.6、PA 8。

调大 → 高速指令真的生效，但超过耗材熔融能力会欠挤出（表面出现缝隙、
层间结合变差）。调小 → 稳定但慢。

> 出现「设了高速却没变快」，先看这一项，而不是以为速度参数写错了。

### 各耗材的官方预设

数值来自 `resources/profiles/BBL/filament/fdm_filament_*.json`：

| 类型 | 喷嘴温度 | 热床（PEI） | 密度 g/cm³ | 体积极限 mm³/s |
|---|---|---|---|---|
| PLA | 220 | 55 | 1.24 | 12 |
| PETG | 255 | 80 | 1.27 | 25 |
| ABS | 270 | 90 | 1.04 | 28.6 |
| ASA | 260 | 90 | 1.04 | 28.6 |
| TPU | 240 | 35 | 1.24 | 15 |
| PC | 280 | 110 | 1.04 | 18 |
| PA | 290 | 100 | 1.04 | 8 |

密度不只是显示用：G-code 头部的 `total filament used [g]` 和 App 里的
耗材重量估算都靠它，设错会让「这卷料够不够」判断失准。

> 引擎对 `filament_type` 的校验是宽松的（`f_enum_open`），
> 传不认识的值**不会报错**。App 会自己检查并在警告区提示。

## 速度（mm/s）

| 参数 | 默认 | 说明 |
|---|---|---|
| 外壁 | 60 | 最影响外观。调到 100 以上会出现振纹 |
| 内壁 | 60 | 可以比外壁快，不明显影响外观 |
| 稀疏填充 | 100 | 最快的一档。它是总时长的主要变量 |
| 内部实心 | 100 | 顶底之间的实心层 |
| 顶面 | 100 | 太快会出现"顶面拉丝" |
| 首层 | 30 | 首层慢一点附着更牢，一般不超过 50 |
| 首层填充 | 60 | 首层内部的填充速度 |
| 空驶 | 120 | 不挤料时的移动速度。调大省时，但太快会让机器抖 |
| 桥接 | 25 | 悬空跨桥必须慢，否则会断 |
| 支撑 | 80 | 支撑本体 |
| 支撑接触面 | 80 | 贴着模型的那几层，太快会粘不牢或撕坏表面 |

> 实际速度还会被**体积极限流速**和**加速度/拐角速度**双重限制。
> 10mm 的小件即使设 200mm/s 也跑不到 —— 这也是为什么调速度后时长变化可能不明显。
> 想看速度参数是否真的生效，别比总时长（小件差异被加速度吃掉），
> 而是看 G-code 里的最大 `F` 值。

## 支撑

| 参数 | 默认 | 说明 |
|---|---|---|
| 悬垂角阈值 | 30° | **最关键的支撑参数**。坡度低于它才生成支撑。调小 → 支撑变多；调到 45 会漏掉大量 30~45° 的悬垂 |
| 支撑类型 | 普通(自动) | `树状` 省料、易剥离，适合有机形状；`普通` 更稳 |
| 接触面层数 | 2 | 支撑与模型之间的致密层。调多 → 表面更好但更难剥 |
| 只在热床上生成 | 关 | 开启后模型内部的悬垂不支撑，省料但可能塌 |
| 过滤小块悬垂 | 开 | 关掉会给很小的凸起也加支撑，通常不划算 |
| 顶面间隙 | 0.20mm | 支撑与模型的垂直缝。**太小会粘死撕坏表面**，0.25~0.3 更好剥 |
| 底面间隙 | 0.20mm | 支撑底与模型的缝 |
| 与模型水平距离 | 0.35mm | 调大 → 好剥但支撑面积变小 |
| 水平外扩 | 0 | 调大让支撑更宽，更容易托住边缘悬垂（0.3~0.5 常用） |
| 底部图案间距 | 2.5mm | 调小 → 支撑更密实、更稳、更费料 |
| 接触面线距 | 0.5mm | 调小 → 接触面更致密 |
| 树状：分枝角 | 30° | 调大 → 枝干更竖直、更省空间；调小 → 更倾斜、更容易避开模型 |
| 树状：主干直径 | 2.0mm | 调大更稳，但更费料 |
| 树状：壁数 | 1 | 2 以上明显更结实 |

> 自动检测漏掉的悬垂，用**手绘支撑笔刷**直接刷在模型上，比调阈值更准。

## 回抽与 Z hop

| 参数 | 默认 | 说明 |
|---|---|---|
| 回抽长度 | 0.8mm | 太短会拉丝，太长（>2mm）容易堵。直驱 0.4~0.8，远程 4~6 |
| 回抽速度 | 30mm/s | 太快会把料拉断在热端里 |
| 最小回抽距离 | 2mm | 空驶超过它才回抽。调小 → 拉丝少但回抽次数暴涨 |
| Z 抬升 | 0.4mm | 回抽时抬头，避免喷嘴刮倒已打好的部分 |
| Z 抬升方式 | 螺旋 | `螺旋` 边抬边回抽，最平滑；`斜向` 沿斜线抬；`普通` 先抬再走 |
| 擦拭 | 关 | 回抽时贴着壁面蹭掉余料，明显减少拉丝 |
| 擦拭距离 | 2mm | 配合擦拭使用，太长会在表面留下痕迹 |
| 避免跨越外墙 | 关 | 开启后空驶绕开外墙，外观更好但更慢 |

## 冷却

| 参数 | 默认 | 说明 |
|---|---|---|
| 最大风扇 | 100% | PLA 常用 100；ABS/PETG 要低，否则层间不粘 |
| 最小风扇 | 20% | 短层时的下限 |
| 前 N 层关风扇 | 1 | 首层关风扇保证附着 |
| 从第 N 层起全速 | 0 | 0 表示不启用该规则 |
| 层耗时阈值 | 60s | 单层快于它就自动降速让层冷却 |
| 最短层时间 | 5s | 降速的目标层时间。**小件打印时这一项会主导总时长** |
| 悬垂风扇 | 100% | 悬垂处的额外冷却 |
| 悬垂/桥接强制冷却 | 开 | 关闭后桥接容易下垂 |

> 关掉「按层耗时自动降速」后，小件的实际速度才会跟着你的速度设置走。
